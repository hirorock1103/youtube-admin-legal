プライバシーポリシー

制定日: 2026年10月30日

「YouTube管理」（以下「本ツール」）は、運営者が自身の YouTube チャンネルを管理するための個人用ツールです。本ポリシーでは、本ツールが Google アカウントを通じて取得する情報の取り扱いを説明します。

1. 取得する情報

本ツールは、利用者が Google アカウントで許可した範囲で、次の情報を読み取り専用で取得します。

  • YouTube Data API: チャンネル情報、投稿動画の情報（タイトル・説明・公開日時・長さ・タグ等）、再生回数・高評価数・コメント数、公開コメント
  • YouTube Analytics API / YouTube Reporting API: 視聴回数、総再生時間、平均視聴時間、平均視聴率、登録者数の増減、共有数、インプレッション数、クリック率

本ツールは動画の投稿・編集・削除、コメントの投稿、チャンネル設定の変更は行いません。

2. 利用目的

取得した情報は、運営者が自身のチャンネルの投稿状況と視聴者の反応を把握するための日報・スプレッドシート・ダッシュボードの作成にのみ使用します。広告、販売、第三者への提供、AI モデルの学習には使用しません。

3. 保存と共有

取得した情報と認証情報は、運営者が管理する非公開の保存場所（運営者のコンピューター、非公開の GitHub リポジトリ、運営者の Google スプレッドシート）にのみ保存し、第三者と共有しません。

4. 保存期間と削除

情報は運営者が本ツールを利用している間保存し、利用を終了した場合は削除します。

5. アクセス権の取り消し

本ツールへのアクセス許可は、Google アカウントのセキュリティ設定からいつでも取り消すことができます。

6. Google および YouTube のポリシー

本ツールは YouTube API サービスを利用しています。本ツールを利用することで、YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いについては Google プライバシーポリシーをご覧ください。

本ツールによる Google API から取得した情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
