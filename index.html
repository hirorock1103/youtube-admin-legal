YouTube管理

YouTube管理は、運営者が自身で所有・管理する YouTube チャンネルの投稿状況と視聴者の反応を、毎日記録して振り返るための個人用ツールです。

できること

  • 運営者のチャンネルに投稿された動画の一覧（タイトル・公開日時・長さなど）の記録
  • 再生回数・高評価数・コメント数の日ごとの推移の記録
  • 視聴維持率・インプレッション数・クリック率などのアナリティクスの記録
  • 上記をまとめた日報・スプレッドシート・ダッシュボードの作成

利用者

本ツールは運営者本人のみが利用するもので、一般には提供していません。YouTube のデータには読み取り専用の権限でのみアクセスし、動画の投稿・編集・削除などは一切行いません。

データの取り扱いについてはプライバシーポリシーをご覧ください。

本ツールは YouTube API サービスを利用しています。
